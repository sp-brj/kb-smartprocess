Предыдущий аудит и его статус: [audit-2026-07-06.md](audit-2026-07-06.md). Секреты (`.env*`) не читались,

## 1. Что это и как работает

**Назначение.** Закрытая корпоративная база знаний SmartProcess (kb.smartprocess.ru): статьи в Markdown,
папки до 3 уровней, wiki-ссылки `[[…]]` с обратными ссылками, теги, история версий с diff/откатом,
публичные share-ссылки (с паролем), экспорт HTML/PDF/DOCX, импорт Markdown, AI-чат по базе (RAG).
Внешний клиент — MCP-агент (`mcp/main.py`, Python, Docker на DevVM), ходит в REST API по API-ключу.

**Стек.** Next.js 15 App Router + React 18, Prisma 6 + Supabase Postgres (pgvector), NextAuth 4
(Credentials, JWT), OpenAI (`text-embedding-3-small` 1536 + `gpt-4o-mini`), Cloudinary, Vercel.

**Объём своего кода** (без generated): API-роуты 3.9K строк, компоненты 5.6K, страницы 2.2K,
`src/lib` 1.1K, MCP 380. Тесты: 36 юнит (vitest), 35 E2E (Playwright, POM).

**Ключевые механизмы**

| Механизм | Где | Как |
|---|---|---|
| Авторизация API | `src/lib/api-auth.ts` | `authenticateRequest()`: Bearer API-ключ (bcrypt) → иначе сессия NextAuth; права из роли |
| Защита страниц | `src/middleware.ts` | `withAuth`, matcher исключает `api`, `login`, `share*` |
| Версии | `api/articles/[id]` PATCH | транзакция: новая `ArticleVersion` при изменении title/content/status |
| Wiki-ссылки | `src/lib/wikilinks-db.ts` | `ArticleLink` пересобирается при create/update; «битые» ссылки дозаполняются при появлении статьи |
| RAG-индекс | `src/lib/reindex.ts` | только PUBLISHED; чанки по H2 ≤2000 симв., hash контента, DELETE+batch INSERT в транзакции |
| RAG-чат | `api/chat` | embed вопроса → top-5 по cosine (`<=>`) → порог 0.6 → SSE-стрим gpt-4o-mini |
| Share-пароль | `src/lib/share-auth.ts` | `/verify` ставит HttpOnly-cookie HMAC(secret, token:passwordHash); проверяют API и страницы |
| Rate-limit | `src/lib/rate-limit.ts` | Upstash при наличии переменных, иначе in-memory; login, share-verify, chat |
| Деплой | `scripts/vercel-build.sh` | `prisma migrate deploy` на production и preview, затем `next build` |

**Состояние на 2026-09-03:** `main` = PR #8 (2026-08-27), дерево чистое. Локально: `tsc` чисто,
`lint` 0 ошибок / 5 warnings, юнит-тесты 36/36. E2E с этого Мака не запустить (Postgres-хендшейк
к Supabase не проходит), в CI E2E тоже нет.

## 2. Оценка: что сделано правильно

- Единая точка авторизации, права выводятся из роли, IDOR на удалении файлов закрыт.
- Серверный гейт share-пароля через подписанную cookie — грамотно (привязка к хешу пароля, constant-time сравнение).
- Санитизация на обоих путях рендера (rehype-sanitize в UI, sanitize-html в экспорте).
- Логин: единое сообщение + bcrypt всегда (нет enumeration/timing), rate-limit.
- Версии и reindex — транзакционно; reindex пакетный, с hash-проверкой (не переэмбеддит без изменений).
- MCP: fail-fast при битом ключе, общий пул, ретраи только там, где безопасно, hard-delete намеренно не выставлен.
- Дисциплина: strict TS, ADR на удаление CRM/аналитики, аудит-док с чеклистом, CI (lint+tsc+unit+build).

Архитектура для задачи адекватна: монолит Next.js + Postgres, без лишних сервисов. Переусложнения нет.

## 3. Проблемы и лишние ходы (по убыванию важности)

### 3.1 🔴 Уязвимые зависимости с готовыми патчами
`npm audit --omit=dev`: 1 critical, 11 high. Почти всё чинится patch-обновлением:

| Пакет | Сейчас | Фикс | Что |
|---|---|---|---|
| next-auth | 4.24.13 | 4.24.15 | **CRITICAL**: homoglyph-обход нормализации email; `getToken()` падает на битом Bearer |
| next | 15.5.11 | 15.5.25 | HIGH: request smuggling в rewrites; неограниченный кэш next/image |
| sharp, postcss, lodash, js-yaml, nanoid, defu | — | `npm audit fix` | транзитивные |
| prisma / @prisma/config | 6.19.1 | см. ниже | HIGH через deepmerge-ts/effect (CLI, не рантайм) |

Prisma: `npm audit` предлагает даунгрейд до 6.12, это неверный совет; проверить 6.19.3 / 7.x отдельно.

### 3.2 🔴 Fire-and-forget на Vercel serverless не гарантирован
[articles/route.ts:149](../src/app/api/articles/route.ts#L149), [articles/[id]/route.ts:135](../src/app/api/articles/[id]/route.ts#L135),
[api-auth.ts:45](../src/lib/api-auth.ts#L45): `reindexArticle(...).catch()` и обновление `lastUsedAt`
запускаются после ответа. Vercel может заморозить функцию сразу после отправки ответа — индекс RAG
молча не обновится. Фикс: обернуть в `after()` из `next/server` (стабилен с Next 15.1).

### 3.3 🟠 Лишний тяжёлый ход: чекбокс → версия → переиндексация
[ArticleContent.tsx:41](../src/components/ArticleContent.tsx#L41): клик по `[ ]` в статье делает PATCH
всего контента → создаётся `ArticleVersion` → hash изменился → полная переиндексация через OpenAI.
Результат: история версий засоряется, платим за эмбеддинги за каждый клик. Фикс: флаг `minor: true`
в PATCH (без версии) + дебаунс reindex, либо не считать изменение только чекбоксов «versionable».

### 3.4 🟠 Четыре пути записи статьи ведут себя по-разному
| Путь | Версия | Wiki-ссылки | Reindex |
|---|---|---|---|
| POST `/api/articles` | ✅ | ✅ | ✅ |
| PATCH `/api/articles/[id]` | ✅ | ✅ | ✅ |
| POST `…/revert` | ✅ | ❌ | ❌ |
| POST `/api/import/markdown` | ❌ | ❌ (и `[[…]]` конвертируется в обычные ссылки — теряются backlinks) | ❌ |

Плюс: перенос статьи в другую папку не переиндексирует, хотя имя папки входит в `headingPath` чанков
(hash считается только по content). Фикс: один сервис `writeArticle()` в `src/lib`, который делают
все четыре роута; импорт хранит `[[…]]` как есть (KB их поддерживает нативно).

### 3.5 🟠 `/api/folders` отдаёт каждую подпапку дважды
[folders/route.ts:13](../src/app/api/folders/route.ts#L13): `findMany` без `where: { parentId: null }`,
но с `include: children` — каждая вложенная папка приходит и как корень, и внутри родителя.
UI фильтрует `!parentId` в Sidebar, MCP — нет (BUG-5 из [BACKLOG-MCP-API.md](../BACKLOG-MCP-API.md), открыт с июня).

### 3.6 🟠 MCP: фильтры теряют данные
- [main.py:180](../mcp/main.py#L180) `list_articles(tag=…, author_email=…)`: фильтрует клиент-сайд поверх
  **первых 100** (дефолт пагинации после PR #8) — результаты молча обрезаются.
- [main.py:284](../mcp/main.py#L284) `search_articles(tag=…)` — `pass`, фильтр не работает.
- [main.py:247](../mcp/main.py#L247) `update_article`: `if title:` — нельзя обнулить папку или очистить контент.
- Бэклог MCP (июнь): все P0 (folder CRUD, backlinks, recent/stats) не начаты; это обёртки над готовыми эндпоинтами.

### 3.7 🟡 Парные роуты с разной авторизацией
`api/upload` (картинки) — `authenticateRequest`; [api/attachments:55](../src/app/api/attachments/route.ts#L55)
(файлы) — `getServerSession`. Вложения нельзя загрузить по API-ключу/из MCP. Аналогично `analytics/track/*`.

### 3.8 🟡 Серверные страницы тянут всё, API — уже нет
[articles/page.tsx:14](../src/app/(dashboard)/articles/page.tsx#L14), `folders/[slug]`, `tags/[slug]`,
[search/page.tsx:24](../src/app/(dashboard)/search/page.tsx#L24): `findMany` с полным `content`, без
`select`/лимита. В PR #8 это починили в `/api/articles`, страницы остались. Страница `/search`
дублирует логику `/api/search` (второй ILIKE, второй сниппет).

### 3.9 🟡 Поиск: `ILIKE %q%` по content без индекса, эмбеддинги заперты в чате
Есть pgvector и готовые чанки, но семантический поиск доступен только через LLM-чат. Нужен
`/api/search/semantic` (без генерации) и FTS `to_tsvector('russian', …)` или pg_trgm для точного.

### 3.10 🟡 Аналитика: публичная запись без потребителя
[track/view](../src/app/api/analytics/track/view/route.ts#L8), [track/search](../src/app/api/analytics/track/search/route.ts#L6):
без auth и без rate-limit, любой бот заполняет `ArticleView`/`SearchQuery`. Читателя нет с ADR-002
(май). Либо retention + лимит, либо снять сбор. Решение ADR остаётся в силе, но защиту добавить.

### 3.11 🟡 bcrypt на каждый API-запрос с ключом
[api-auth.ts:40](../src/lib/api-auth.ts#L40): ключ — 256 бит случайности, bcrypt (cost 10) даёт
~50–100 мс на каждый tool-call MCP без пользы (перебор невозможен). SHA-256 достаточно и мгновенен.
Переход: хранить sha256, ключи перевыпустить (их единицы) или временно проверять оба.

### 3.12 🟡 RAG-мелочи
- `history` в `/api/chat` не ограничен по длине — клиент может прислать сколько угодно токенов.
- `gpt-4o-mini` и порог 0.6 захардкожены; спека UI-настроек ([design-ai-settings-ui.md](design-ai-settings-ui.md), 25 КБ) лежит с мая без реализации — либо делать, либо признать неактуальной.
- Нет индекса на `embedding` (HNSW) — пока чанков мало, seq scan нормально; вернуться при >10K чанков.

### 3.13 🟡 Инфра-хвосты (открыты с июля)

  в CI job нет. 35 тестов и новые share-спеки ни разу не выполнялись после PR #8.
- Три устаревшие ветки на origin: `feature/collapsible-sidebar` (0 уникальных коммитов),
  `chore/tech-debt-2026-08` (squash-смержена), `chore/migrate-on-prod-build` (перекрыта #3).

### 3.14 🟢 Гигиена доков и локальные хвосты

## 5. Обход глазами пользователя (Claude in Chrome, прод, 2026-09-03)

Открывал kb.smartprocess.ru под учёткой владельца, ширина 1547 px и 600/500 px. Только чтение:
ничего не создавал, не публиковал, не удалял. Проверены: список статей, папка, статья, поиск
(выпадашка и страница), теги, настройки, редактор (без сохранения), AI-чат, модалки «Поделиться»
и «История изменений», меню «⋮», консоль и сеть.

### 🔴 React error #418 (hydration mismatch) на `/articles`
Воспроизводится при каждой загрузке главной, на страницах статьи и `/tags` ошибки нет.
Причина: [ArticlesList.tsx:96](../src/components/ArticlesList.tsx#L96) форматирует дату
`toLocaleDateString("ru-RU")` в клиентском компоненте. Сервер (Vercel, UTC) и браузер (MSK) дают
разные даты для статей, обновлённых между 21:00 и 00:00 MSK. Проверено через API: 4 из 148 статей
попадают (например `2026-08-27T22:08Z` → «27.08» на сервере, «28.08» у клиента). React отбрасывает
серверную разметку списка и рендерит заново. Фикс: `timeZone: "Europe/Moscow"` в опциях или готовая
строка с сервера.

### 🟠 Нет адаптивной вёрстки
При 600 и 500 px сайдбар остаётся фиксированной ширины, шапка и контент обрезаны, горизонтальный
скролл (`scrollWidth` 951 при `innerWidth` 500). В layout, Sidebar, Header нет ни одного `md:`/`lg:`
класса. На телефоне база непригодна. Ширину 390 проверить не удалось: минимальная ширина окна
Chrome на macOS около 500 px.

### 🟠 Сайдбар не закреплён
[Sidebar.tsx:250](../src/components/Sidebar.tsx#L250): `h-screen overflow-y-auto` без `sticky top-0`.
При прокрутке длинной статьи или списка на 148 строк сайдбар уезжает вверх, слева остаётся пустая
тёмная область (видно на скриншотах после прокрутки).

### 🟠 Модалки не закрываются по Escape
«Публичная ссылка» и «История изменений» остаются открытыми после Escape (в `ShareLinkManager` нет
обработчика клавиш). Меню «⋮» и меню пользователя по Escape закрываются, поведение непоследовательно.

### 🟡 AI-чат: нет автофокуса на поле ввода
После клика «Спросить AI» фокус остался в поиске: набранный вопрос улетел в строку поиска и открыл
`/search?q=keeneticКак подключить…`. Сам чат работает: ответ по статье о Zabbix пришёл примерно за
10 секунд, релевантный, со ссылкой на источник.

### 🟡 Сниппеты поиска с сырой разметкой
В выпадашке и на `/search` видны `<div align="center"><h2>НАЗНАЧЕНИЕ</div>`, `**Keenetic**`, slug'и
ссылок. Сниппет режется из raw `content` без очистки (см. также BUG-4 в бэклоге MCP про
гибрид Markdown+HTML в статьях).

### 🟡 Slug с меткой времени
`/articles/ustanovit-i-proizvesti-bazovye-nastroyki-servernoy-windows-1788236683082`: при коллизии
к slug добавляется `Date.now()`. Некрасиво и непредсказуемо, лучше `-2`, `-3`.

### 🟡 Мелочи

  прокрутилась). Воспроизвести повторно не пытался, стоит проверить руками.

Список и папки с хлебными крошками, поиск «keenetic» отдал релевантные результаты быстрее 3 с,
страница статьи читаемая, история версий, настройки профиля, редактор с тулбаром и превью,
